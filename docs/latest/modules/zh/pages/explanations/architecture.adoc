= 整体架构
:page-languages: [zh]
:revdate: 2026-08-23
:page-revdate: {revdate}
:description: 对 {project-name} 的多智能体架构的介绍。

该系统被设计为一个**分层多智能体生态系统**。它使用一个**中央智能体（Supervisor Agent）** 跨多个**专用 AI 智能体**来编排和调度请求，每个智能体都连接到一个或多个** MCP（模型上下文协议）服务**。


== 核心组件

=== 中央智能体

中央智能体（Supervisor Agent）是系统的入口点和用户体验的协调器。中央智能体并不是直接执行每个技术任务，而是充当一个**智能路由器**。

* 分析用户的问题以确定所需的域（例如安全、配置或持续交付）。
* 查阅 SubAgentConfig 元数据来选择最适合任务的专用智能体去完成任务。
* 在 Rancher UI 中，可以跟踪用户的位置，并确保相关集群、命名空间和资源元数据传递到下游智能体以提供“上下文感知”的响应。
* 在独立 UI 中，可以选择用户要操作的集群，或者在用户问题中指定相关集群、命名空间和资源元数据传递到下游智能体以提供“上下文感知”的响应。

=== 专用智能体团队

专用智能体团队（Specialized Agent Crew）是系统的主力。每个智能体都是其特定领域智能的编排者，它使用大型语言模型（LLM）作为推理引擎，而其本身负责提供动作的结构、协调和安全执行。

* **大语言模型（推理引擎）**：
** 解释以自然语言表达的用户输入。
** 执行推理：将复杂的请求分解为更小的步骤。
** 决定接下来应该发生什么（继续推理还是采取行动）。
** 将工具的输出总结输出为清晰、易于人类理解的回答。

* **智能体（编排者）**：
** 用 ReAct（推理 + 行动）模式包装大语言模型。
** 决定何时让大语言模型继续推理或何时按照其指示采取行动。
** 按照大语言模型的指示调用外部工具（通过 MCP 服务）。
** 通过将用户的 Token 传递到 MCP 服务器进行身份验证和鉴权，确保安全交互。


=== MCP 服务

MCP 服务充当 ReAct 智能体 与 Rancher 和 Kubernetes API 之间的安全受控网关。其功能包括：

* **暴露工具**：它提供一组定义明确、安全的工具（API 端点），供 ReAct Agent 调用。这些工具抽象化了直接与 Rancher/Kubernetes API 交互的复杂性。
* **与 Rancher 交互**：它将来自智能体的工具调用转换为发送至 Rancher 管理服务器的相应 API 请求，并根据需要检索或修改资源。
* **与 Kubernetes 交互**：它将来自智能体的工具调用转换为发送至 Kubernetes 管理服务器的相应 API 请求，并根据需要检索或修改资源。

=== Rancher UI 扩展 / 独立 UI

在 Rancher UI 和 独立 UI 中都提供面向用户的聊天界面，它旨在无缝融入 Rancher/Kubernetes 用户体验，其功能包括：

* **用户输入**：它捕获用户查询并将其发送给 ReAct 智能体。
* **显示回复**：它接收来自 ReAct 智能体的回复，并以聊天格式呈现。除了正常的文本消息回复，还会根据回复内容提供如资源跳转、YAML展示、YAML变化展示和建议展示等多种可视化 UI 功能的支持。


== 工作原理（流程）

1. **用户提问**：用户通过 UI 提交问题。
2. **中央智能体路由**：中央智能体（Supervisor Agent）通过 LLM 确定意图并将拆解后的问题以及 UI 上下文路由到专用智能体（例如，Rancher 智能体）。
3. **LLM 推理**：专用智能体的 LLM 负责解释请求、推理问题，并提出行动计划。
4. **专用智能体执行**：如果计划需要外部操作，智能体将使用用户的 Token 调用合适的 MCP 服务工具。
5. **专用智能体响应**：LLM 总结智能体内的工具的所有输出并制定连贯的、人类可读的响应返回给中央智能体。
6. **最终响应**：中央智能体（Supervisor Agent）综合所有智能体的回答做总结后形成最终回答，然后传送回 UI 给用户看。

<script>
(function () {
  var MIN = 0.4;
  var MAX = 5;
  var STEP = 0.05;

  function ready(fn) {
    if (document.readyState === 'loading') document.addEventListener('DOMContentLoaded', fn);
    else fn();
  }

  ready(function () {
    var overlay = document.createElement('div');
    overlay.className = 'mermaid-lightbox';
    overlay.setAttribute('role', 'dialog');
    overlay.setAttribute('aria-modal', 'true');
    overlay.innerHTML =
      '<div class="mermaid-lightbox__panel">' +
        '<button type="button" class="mermaid-lightbox__close" aria-label="关闭">×</button>' +
        '<div class="mermaid-lightbox__toolbar">' +
          '<button type="button" data-zoom="-">−</button>' +
          '<span class="mermaid-lightbox__zoom">100%</span>' +
          '<button type="button" data-zoom="+">+</button>' +
          '<button type="button" data-zoom="reset">重置</button>' +
          '<span class="mermaid-lightbox__hint">滚轮缩放，拖动查看</span>' +
        '</div>' +
        '<div class="mermaid-lightbox__viewport">' +
          '<div class="mermaid-lightbox__stage"></div>' +
        '</div>' +
      '</div>';
    document.body.appendChild(overlay);

    var viewport = overlay.querySelector('.mermaid-lightbox__viewport');
    var stage = overlay.querySelector('.mermaid-lightbox__stage');
    var zoomLabel = overlay.querySelector('.mermaid-lightbox__zoom');
    var closeBtn = overlay.querySelector('.mermaid-lightbox__close');
    var state = { scale: 1, x: 0, y: 0, dragging: false, lastX: 0, lastY: 0 };

    function apply() {
      stage.style.transform = 'translate(' + state.x + 'px, ' + state.y + 'px) scale(' + state.scale + ')';
      zoomLabel.textContent = Math.round(state.scale * 100) + '%';
    }

    function setScale(next, cx, cy) {
      next = Math.min(MAX, Math.max(MIN, next));
      if (typeof cx === 'number') {
        var ratio = next / state.scale;
        state.x = cx - (cx - state.x) * ratio;
        state.y = cy - (cy - state.y) * ratio;
      }
      state.scale = next;
      apply();
    }

    function center() {
      state.scale = 1;
      var sw = stage.offsetWidth;
      var sh = stage.offsetHeight;
      state.x = Math.max(0, (viewport.clientWidth - sw) / 2);
      state.y = Math.max(0, (viewport.clientHeight - sh) / 2);
      apply();
    }

    function close() {
      overlay.classList.remove('is-open');
      document.body.style.overflow = '';
      stage.innerHTML = '';
    }

    function open(svg) {
      stage.innerHTML = '';
      var clone = svg.cloneNode(true);
      clone.removeAttribute('width');
      clone.removeAttribute('height');
      stage.appendChild(clone);
      overlay.classList.add('is-open');
      document.body.style.overflow = 'hidden';
      requestAnimationFrame(center);
    }

    function bind(el) {
      if (el.dataset.lightboxBound) return;
      var svg = el.querySelector('svg');
      if (!svg) return;
      el.dataset.lightboxBound = 'true';
      el.setAttribute('title', '单击放大');
      el.addEventListener('click', function (e) {
        e.preventDefault();
        var sel = window.getSelection();
        if (sel) sel.removeAllRanges();
        open(svg);
      });
    }

    function tryBind() {
      document.querySelectorAll('.doc .mermaid').forEach(bind);
    }

    overlay.querySelector('[data-zoom="-"]').addEventListener('click', function () {
      setScale(state.scale - STEP, viewport.clientWidth / 2, viewport.clientHeight / 2);
    });
    overlay.querySelector('[data-zoom="+"]').addEventListener('click', function () {
      setScale(state.scale + STEP, viewport.clientWidth / 2, viewport.clientHeight / 2);
    });
    overlay.querySelector('[data-zoom="reset"]').addEventListener('click', center);

    viewport.addEventListener('wheel', function (e) {
      e.preventDefault();
      var rect = viewport.getBoundingClientRect();
      setScale(state.scale + (e.deltaY > 0 ? -STEP : STEP), e.clientX - rect.left, e.clientY - rect.top);
    }, { passive: false });

    viewport.addEventListener('pointerdown', function (e) {
      if (e.button !== 0) return;
      state.dragging = true;
      state.lastX = e.clientX;
      state.lastY = e.clientY;
      viewport.classList.add('is-dragging');
      viewport.setPointerCapture(e.pointerId);
    });
    viewport.addEventListener('pointermove', function (e) {
      if (!state.dragging) return;
      state.x += e.clientX - state.lastX;
      state.y += e.clientY - state.lastY;
      state.lastX = e.clientX;
      state.lastY = e.clientY;
      apply();
    });
    function endDrag() {
      state.dragging = false;
      viewport.classList.remove('is-dragging');
    }
    viewport.addEventListener('pointerup', endDrag);
    viewport.addEventListener('pointercancel', endDrag);

    closeBtn.addEventListener('click', close);
    overlay.addEventListener('click', function (e) {
      if (e.target === overlay) close();
    });
    document.addEventListener('keydown', function (e) {
      if (e.key === 'Escape') close();
    });

    tryBind();
    var root = document.querySelector('.doc') || document.body;
    new MutationObserver(tryBind).observe(root, { childList: true, subtree: true });
  });
})();
</script>
