[#getting-started]
== 开始使用 {short-project-name}^GC^

{short-project-name}^GC^ 包含一个常驻的 AI 助手 *{short-project-name}^GC^*。 您可以随时在 UI 中点击 *{short-project-name}^GC^ 图标* image:how-to-user/liz-button.png[Liz GC 图标, width=48] 打开助手。

打开侧边栏后，{short-project-name}^GC^ 会显示欢迎消息，其中包含使用提示、简短的新闻资讯以及帮助您快速开始使用的建议列表（请参考 xref:/how-tos/how-to-admin.adoc#ui-tools[ui-tools] 部分）。

image::how-to-user/chat-panel.png[Liz GC 聊天面板, align="left",  width="50%"]

[#context-aware]
== 上下文感知

{short-project-name}^GC^ 可以准确理解您当前正在查看的内容。任何带有状态标记的资源都会显示 *Ask {short-project-name}^GC^* 按钮。

.  点击资源旁边的 *Ask {short-project-name}^GC^ 滑动按钮图标*。image:how-to-user/ask-liz.png[Ask Liz GC 图标, align="center"]
.  侧边栏将打开，并自动针对该资源生成相应的提示词。
.  {short-project-name}^GC^ 会自动获取资源名称、集群 ID 和命名空间，从而提供准确的帮助。

image::how-to-user/context.png[Liz GC 上下文界面显示集群和命名空间感知能力。, align="center"]

[#user-approve]
== 审批操作

安全是首要考虑的因素。

当您要求 {short-project-name}^GC^ 或其专用 Agent 执行可能影响集群或工作负载的变更操作（例如更新 Deployment、修改集群配置）时，系统会暂停执行，并提示会提示 *等待人工授权执行*。

image::how-to-user/approve.png[环境修改确认对话框。, width="50%", align="left"]

只有在您点击 *Allow* 并明确授权后，{short-project-name}^GC^ 才会执行相应操作并将变更应用到目标环境。

[#managing-conversations]
== 管理对话

您可以同时进行多个线程操作，也可以保存历史记录以供日后参考。

* *创建新聊天:* 要开始新的会话，请点 *Start a New Chat* 按钮。

image:how-to-user/conversation.png[New Chat 图标, width="50%"]

* *复制历史记录:* 要保存您的会话记录，请点击页面右上角的复制按钮。复制后，可以粘贴内容到文本保存。

image:how-to-user/copy.png[复制按钮, width="50%"]

[#manual-agent-selection]
== 切换 Agents
默认情况下，{short-project-name}^GC^ 使用 "智能路由"（Smart Routing）将您的请求发送给最合适的专用 Agent（例如，针对漏洞问题使用 Security Agent）。

如果您希望手动选择特定的 Agent：

. 点击 *Agent Selection* 图标.
+
image:how-to-user/multi-agent-selection.png[Agent 选择按钮, width="50%"]

. 从列表中选择所需的 Agent。

NOTE: 如果 {short-project-name}^GC^ 检测到您频繁使用同一个 Agent，可能会建议您在当前会话中切换到手动模式。

== 提示词示例

不知道从哪里开始？不妨问问 {short-project-name}^GC^ 这些问题：

[cols="1,2,1", options="header"]
|===
| 类别 | 用户提示词 | 处理 Agent

| *故障排除* | "应用运行缓慢，请找出根本原因。" | *SUSE Observability Agent* （分析指标和日志）
| *技能提升* | "如何在 Rancher 中安装 Helm Chart？" | *Knowledge *（提供文档来源）
| *集群置备* | "分析集群并排查其中存在的问题。" | *Rancher-Provisioning Agent* （检查基础设施运行状况）
|===
