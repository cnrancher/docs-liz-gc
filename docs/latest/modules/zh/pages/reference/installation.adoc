本文介绍如何在已有的 Kubernetes 集群中安装 {short-project-name}^GC^ 应用，并介绍相关的安装参数。

== 常规选项

[cols="1,1,3", options="header"]
|===
| 参数 | 默认值 | 描述

| bootstrapPassword
| ""
| string - 设置第一个管理员用户的引导密码。如果未设置该值，则使用随机生成的引导密码

| hostname
| ""
| string - {short-project-name}^GC^ 访问的完全域名

| llm.provider
| "google_genai"
| string - LLM 模型提供商，例如 `openai`, `google_genai`

| llm.baseURL
| ""
| string - LLM API 的访问地址，例如 Qwen `https://dashscope.aliyuncs.com/compatible-mode/v1`

| llm.apiKey
| ""
| string - LLM API Key

| llm.model
| "gemini-3-flash-preview"
| string - LLM 提供商支持的模型名称

| llm.active
| "gemini"
| string - 当前使用的模型
|===

== 高级选项

== TLS 选项

本节配置仅适用于使用独立 UI 的部署模式。

{short-project-name}^GC^ 使用 Kubernetes Ingress 提供 HTTPS 访问，TLS 由集群的 Ingress 控制器负责处理。用户需要选择使用的 Ingress 控制器，并根据实际情况配置 TLS。

集成到 Rancher UI 时，HTTPS 访问和证书管理由 Rancher 负责，{short-project-name}^GC^ 无需单独配置 TLS，以下选项无需配置。

[cols="1,1,3", options="header"]
|===
| 参数 | 默认值 | 描述

| tls
| ""
| string - 设置为空值或者 `ingress`

| privateCA
| false
| bool - 如果使用自签名证书，需要设置为 `true`

| ingress.enabled
| true
| bool - 是否启用 ingress 控制器，如果设置 `tls='ingress'`，这里必须设置为 true
|===

== SSL 配置

{short-project-name}^GC^ 默认需要配置 SSL/TLS 协议。

本节仅适用于使用独立 UI 的部署模式。集成到 Rancher UI 时，{short-project-name}^GC^ 无需单独配置 SSL/TLS。

独立 UI 模式下，Liz GC 需要配置 SSL/TLS，以保护 WebSocket 和 HTTPS 通信。

[NOTE]
====

如果您希望从外部终止 SSL/TLS 连接，请参阅 <<external-tls,在外部负载均衡器上终止 TLS>>相关内容，此选项对 TLS 验证有一些额外的要求。

====

独立 UI 模式支持以下两种证书配置方案：

* **使用 {short-project-name}^GC^ 生成的 TLS 证书**：需要在集群中安装 `cert-manager`。{short-project-name}^GC^ 会自动生成 CA 证书，并使用该 CA 签发 TLS 证书，后续由 cert-manager 负责证书管理。
* **使用自定义证书**：可以使用由公共或私有 CA 签发的证书。需要将证书及对应的私钥以 PEM 格式上传，文件名分别为 tls.crt 和 tls.key。如果使用私有 CA，还需要提供对应的 CA 证书，以确保相关节点能够信任该证书。

=== {short-project-name}^GC^ 自动生成 TLS 证书

以下示例适用于独立 UI 部署模式：

[source,bash,subs="attributes+"]
----
# install cert-manager
helm repo add jetstack https://charts.jetstack.io

helm install cert-manager jetstack/cert-manager \
  --namespace cert-manager \
  --create-namespace --set crds.enabled=true

# install Liz GC
helm upgrade --install \
    -n kopilot-system \
    --create-namespace \
    kopilot-crd ./kopilot-crd-{page-version}.tgz

helm upgrade --install \
    -n kopilot-system \
    --create-namespace \
    --set bootstrapPassword="<your bootstrap password>" \
    --set hostname="<your domain>" \
    --set tls="ingress" \
    --set llm.active=gemini \
    --set llm.provider=google_genai \
    --set llm.apiKey="<your llm api key>" \
    kopilot ./kopilot-{page-version}.tgz
----

=== 使用自定义证书

以下示例适用于独立 UI 部署模式：

[source,bash,subs="attributes+"]
----
kubectl create namespace kopilot-system
kubectl -n kopilot-system create secret tls tls-kopilot-ingress --cert=./tls.crt --key=./tls.key
kubectl -n kopilot-system create secret generic tls-kopilot-ca --from-file=cacerts.pem

helm upgrade --install \
    -n kopilot-system \
    --create-namespace \
    kopilot-crd ./kopilot-crd-{page-version}.tgz

helm upgrade --install \
    -n kopilot-system \
    --create-namespace \
    --set bootstrapPassword="<your bootstrap password>" \
    --set hostname="<your domain>" \
    --set llm.active=gemini \
    --set llm.provider=google_genai \
    --set llm.apiKey="<your llm api key>" \
    --set tls="ingress" \
    --set privateCA=true \
    kopilot ./kopilot-{page-version}.tgz
----

[[external-tls]]
=== 在外部负载均衡器上终止 TLS

如果使用外部负载均衡器处理 HTTPS，负载均衡器必须支持长期存在的 WebSocket 连接，并正确传递代理头信息，以便 {short-project-name}^GC^ 正确处理请求。

==== Required Headers
* Host
* X-Forwarded-Proto
* X-Forwarded-Port
* X-Forwarded-For

==== Recommended Timeouts

* Read Timeout: 1800 seconds
* Write Timeout: 1800 seconds
* Connect Timeout: 30 seconds

[source,bash,subs="attributes+"]
----
helm upgrade --install \
    -n kopilot-system \
    --create-namespace \
    kopilot-crd ./kopilot-crd-{page-version}.tgz

helm upgrade --install \
    -n kopilot-system \
    --create-namespace \
    --set bootstrapPassword="<your bootstrap password>" \
    --set llm.active=gemini \
    --set llm.provider=google_genai \
    --set llm.apiKey="<your llm api key>" \
    --set tls="" \
    --set rancher_sso.enabled=true \
    --set rancher_sso.url="<your rancher url>" \
    kopilot ./kopilot-{page-version}.tgz
----

以下是用于配置外部负载均衡器的 NGINX 示例：

[source,bash]
----
# nginx.conf
worker_processes 4;
worker_rlimit_nofile 40000;

events {
    worker_connections 8192;
}

http {
    upstream kopilot {
        server IP_NODE:80;
    }

    map $http_upgrade $connection_upgrade {
        default Upgrade;
        ''      close;
    }

    server {
        listen 443 ssl http2;
        server_name FQDN;
        ssl_certificate /etc/cert/tls.crt;
        ssl_certificate_key /etc/cert/tls.key;

        location / {
            proxy_set_header Host $host;
            proxy_set_header X-Forwarded-Proto $scheme;
            proxy_set_header X-Forwarded-Port $server_port;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_pass http://kopilot;
            proxy_http_version 1.1;
            proxy_set_header Upgrade $http_upgrade;
            proxy_set_header Connection $connection_upgrade;
            # This allows the execution shell window to remain open for up to 15 minutes.
            # It will automatically turn off after 1 minute by default.
            proxy_read_timeout 900s;
            proxy_buffering off;
        }
    }

    server {
        listen 80;
        server_name FQDN;
        return 301 https://$server_name$request_uri;
    }
}
----
